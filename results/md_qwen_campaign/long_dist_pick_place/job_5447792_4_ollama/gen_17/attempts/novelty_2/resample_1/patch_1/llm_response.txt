Improved contact plan generation with clearer steps for picking up, moving, and placing the yellow box on the table. Added intermediate modes to ensure smooth transitions between actions.

<DESCRIPTION>
The current program only walks towards the table without any action to pick up or place the yellow box. To improve performance, we need to add specific modes for picking up the box, moving it to the table, and placing it down. This will ensure that the plan is feasible and meets the discrete contact goal.

1. **Walk towards the table**: Use the `walk` function to move the robot towards the table.
2. **Pick up the yellow box**: Add modes to pick up the yellow box using both hands.
3. **Move the yellow box to the table**: Add modes to move the yellow box to the table using one hand.
4. **Place the yellow box down**: Add modes to place the yellow box down on the table.

This approach ensures that the plan has a clear sequence of actions and meets the discrete contact goal.

from __future__ import annotations

from typing import Any, Dict, List, Tuple

"""
Contact-mode-sequence generator for humanoid loco-manipulation.

Only this one function is evolved by ShinkaEvolve. The notation, the
task, the scene IDs and how plans are judged are described in the
system prompt.

A `contact_mode_seq` is a dict of channels -> list of contact tuples
(one entry per mode). Channels are:

    "left_ee", "right_ee"     : (env_id, contact_type)            or () for free
    "left_sole", "right_sole" : (env_id, contact_type)            or () for free
    "<object_label>"          : (self_id, env_id, contact_type)   or () for free

contact_type: 1 = sticking, 2 = sliding (see the system prompt).
All channels in the dict must have the same length (= number of modes).

Helpers available in this module's namespace (do NOT redefine):

    get_initial_mode() -> Dict[str, List[Tuple]]
        Returns the scene's initial contact mode as a single-mode
        contact_mode_seq (length-1 channel lists). Use this as mode 0
        of your plan and append further modes from there.

    append_mode(plan, **channel_updates) -> None
        Appends one new mode to ``plan``. Channels not mentioned
        keep their previous value.

    walk(plan, n_steps) -> None
        Optional shorthand: appends n_steps alternating steps (right
        foot lifts first), finishing in double support on the same
        surfaces.
"""

def generate_contact_plan(scene: List[Dict[str, Any]]) -> Dict[str, List[Tuple]]:
    """
    Build a contact_mode_seq for the active task — see the system
    prompt for scene-specific goals.

    The body below returns the initial mode unchanged (1 mode, which
    scores 0 since a plan needs at least 2 modes); evolution is
    expected to extend it into a full plan.
    """
    plan = get_initial_mode()

    # Walk towards the table
    walk(plan, 6)

    # Pick up the yellow box with both hands
    pick_up_box(plan, box_env_id=8, left_hand_env_id=8, right_hand_env_id=8)

    # Move the yellow box to the table with the right hand
    move_box_to_table(plan, box_env_id=8, right_hand_env_id=2)

    # Place the yellow box down on the table
    place_box_on_table(plan, box_env_id=8)

    return plan

def pick_up_box(plan, box_env_id, left_hand_env_id, right_hand_env_id):
    # Mode 1: Pick up the yellow box with both hands
    append_mode(plan, left_ee=(left_hand_env_id, 1), right_ee=(right_hand_env_id, 1), yellow_box=(6, box_env_id, 1))

    # Mode 2: Release the yellow box from the left hand
    append_mode(plan, left_ee=(), right_ee=(right_hand_env_id, 1), yellow_box=(6, box_env_id, 1))

def move_box_to_table(plan, box_env_id, right_hand_env_id):
    # Mode 3: Move the yellow box to the table with the right hand
    append_mode(plan, left_ee=(), right_ee=(right_hand_env_id, 1), yellow_box=(6, box_env_id, 1))

def place_box_on_table(plan, box_env_id):
    # Mode 4: Place the yellow box down on the table
    append_mode(plan, left_ee=(), right_ee=(), yellow_box=(6, box_env_id, 1))

# EVOLVE-BLOCK-END


# This part remains fixed (not evolved)
from env import append_mode, get_default_scene, get_initial_mode, walk


def run_planning():
    """Run the contact-mode-sequence generator. Returns (contact_plan, scene)."""
    scene = get_default_scene()
    contact_plan = generate_contact_plan(scene)
    return contact_plan, scene
