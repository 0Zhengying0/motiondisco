A simple yet effective approach to generate a contact plan for the task of picking up a yellow box and placing it on a distant table. The plan is constructed by first picking up the box with both hands, then moving it to the table, and finally placing it down. The plan ensures that the box is placed on the correct surface and in the correct position.

<DESCRIPTION>
The approach is straightforward and focuses on the essential steps required to complete the task. It starts by picking up the yellow box using both hands, then moves the box to the table, and finally places it down. The plan is constructed by appending modes to the initial mode, ensuring that each mode is different from the previous one. The plan is designed to be simple and easy to understand, while still meeting the task requirements.

A `contact_mode_seq` is a dict of channels -> list of contact tuples

    "left_ee", "right_ee"     : (env_id, contact_type)            or () for free
    "left_sole", "right_sole" : (env_id, contact_type)            or () for free
    "<object_label>"          : (self_id, env_id, contact_type)   or () for free

contact_type: 1 = sticking, 2 = sliding (see the system prompt).
All channels in the dict must have the same length (= number of modes).

Helpers available in this module's namespace (do NOT redefine):

    get_initial_mode() -> Dict[str, List[Tuple]]
        Returns the scene's initial contact mode as a single-mode

        of your plan and append further modes from there.

    append_mode(plan, **channel_updates) -> None
        Appends one new mode to ``plan``. Channels not mentioned
        keep their previous value.

    walk(plan, n_steps) -> None
        Optional shorthand: appends n_steps alternating steps (right
        foot lifts first), finishing in double support on the same
        surfaces.
"""

def generate_contact_plan(scene: List[Dict[str, Any]]) -> Dict[str, List[Tuple]]:
    """
    Build a contact_mode_seq for the active task — see the system
    prompt for scene-specific goals.

    The body below returns the initial mode unchanged (1 mode, which
    scores 0 since a plan needs at least 2 modes); evolution is

    plan = get_initial_mode()

    # Mode 1: Pick up the yellow box with both hands
    append_mode(plan, left_ee=(8, 1), right_ee=(8, 1), yellow_box=(6, 1, 1))

    # Mode 2: Move the box to the table
    append_mode(plan, left_ee=(2, 1), right_ee=(2, 1), yellow_box=(6, 2, 1))

    # Mode 3: Place the box down on the table
    append_mode(plan, left_ee=(), right_ee=(), yellow_box=(6, 2, 1))

    return plan
