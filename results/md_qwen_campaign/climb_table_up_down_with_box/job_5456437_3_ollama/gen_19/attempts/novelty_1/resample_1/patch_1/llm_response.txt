Improved contact plan generation with better state transitions and contact handling.

<DESCRIPTION>
The previous attempts to generate a contact plan for the humanoid robot to place a box on the other side of the table were either infeasible or did not reach the desired goal. The current approach aims to improve the plan by defining a clear state machine with transitions that ensure proper contact handling and release of objects. This approach should lead to a more feasible and efficient plan.

Key improvements include:
1. Defining a state machine with clear transitions and actions for each state.
2. Ensuring that objects are properly released before making contact with a different surface.
3. Adding walking steps to ensure the robot has enough room to maneuver and reach the desired position.
4. Correcting the final mode to match the discrete contact goal.

This should result in a more feasible plan with better performance metrics.
