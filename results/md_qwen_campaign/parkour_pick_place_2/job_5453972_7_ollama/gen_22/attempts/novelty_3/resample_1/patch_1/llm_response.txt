Optimized pick and place plan with fewer modes and corrected contact transitions.

<DESCRIPTION>
The proposed program optimizes the contact sequence for a pick-and-place task by reducing the number of modes and ensuring correct contact transitions. The plan starts by moving the robot's hands to the white box, lifting it, walking to the elevated table, and then placing the box on the table. The key improvements include:
1. Reducing the number of modes by directly moving to the elevated table after lifting the box.
2. Ensuring that contacts are released before switching to a different surface, as required by the solver.
3. Using the `walk` function to move the robot to the elevated table, which provides more steps for the solver to position the robot correctly.

    # Move right_ee to the white box
    append_mode(plan, right_ee=(14, 1))

    # Lift the white box
    append_mode(plan, left_ee=(), right_ee=(), white_box=(6, 1, 2))

    # Walk to the elevated table
    walk(plan, 5)

    # Move left_ee to the elevated table
    append_mode(plan, left_ee=(8, 1))

    # Move right_ee to the elevated table
    append_mode(plan, right_ee=(8, 1))

    # Release the white box
    append_mode(plan, left_ee=(), right_ee=(), white_box=())

    # Place the white box on the elevated table
    append_mode(plan, left_ee=(), right_ee=(), white_box=(6, 8, 1))

from env import append_mode, get_default_scene, get_initial_mode, walk
