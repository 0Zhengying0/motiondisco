This approach uses a state machine to manage transitions between different phases of the task. The state machine will handle the lifting of the feet, the movement of the hands, and the placement of the box. This ensures that each transition is handled correctly, avoiding the need for manual mode appending and reducing the risk of errors. The state machine will also ensure that the robot's feet are on the table and holding the box at the end of the task.

"""
Contact-mode-sequence generator for humanoid loco-manipulation.

Only this one function is evolved by ShinkaEvolve. The notation, the
task, the scene IDs and how plans are judged are described in the
system prompt.

A `contact_mode_seq` is a dict of channels -> list of contact tuples
(one entry per mode). Channels are:

    "left_ee", "right_ee"     : (env_id, contact_type)            or () for free
    "left_sole", "right_sole" : (env_id, contact_type)            or () for free
    "<object_label>"          : (self_id, env_id, contact_type)   or () for free

contact_type: 1 = sticking, 2 = sliding (see the system prompt).
All channels in the dict must have the same length (= number of modes).

Helpers available in this module's namespace (do NOT redefine):

    get_initial_mode() -> Dict[str, List[Tuple]]
        Returns the scene's initial contact mode as a single-mode
        contact_mode_seq (length-1 channel lists). Use this as mode 0
        of your plan and append further modes from there.

    append_mode(plan, **channel_updates) -> None
        Appends one new mode to ``plan``. Channels not mentioned
        keep their previous value.

    walk(plan, n_steps) -> None
        Optional shorthand: appends n_steps alternating steps (right
        foot lifts first), finishing in double support on the same
        surfaces.
"""

def generate_contact_plan(scene: List[Dict[str, Any]]) -> Dict[str, List[Tuple]]:
    """
    Build a contact_mode_seq for the active task — see the system
    prompt for scene-specific goals.

    The body below returns the initial mode unchanged (1 mode, which
    scores 0 since a plan needs at least 2 modes); evolution is
    expected to extend it into a full plan.
    """
    plan = get_initial_mode()

    # Define states
    states = {
        'initial': 0,
        'lift_right_foot': 1,
        'move_right_foot_to_table': 2,
        'lift_left_foot': 3,
        'move_left_foot_to_table': 4,
        'lift_right_hand': 5,
        'move_left_hand_to_box': 6,
        'lift_box': 7,
        'move_box_to_table': 8,
        'place_box_on_table': 9,
        'final': 10
    }

    # Define transitions
    transitions = {
        'initial': 'lift_right_foot',
        'lift_right_foot': 'move_right_foot_to_table',
        'move_right_foot_to_table': 'lift_left_foot',
        'lift_left_foot': 'move_left_foot_to_table',
        'move_left_foot_to_table': 'lift_right_hand',
        'lift_right_hand': 'move_left_hand_to_box',
        'move_left_hand_to_box': 'lift_box',
        'lift_box': 'move_box_to_table',
        'move_box_to_table': 'place_box_on_table',
        'place_box_on_table': 'final'
    }

    # Define actions for each state
    actions = {
        'lift_right_foot': lambda: append_mode(plan, right_sole=()),
        'move_right_foot_to_table': lambda: append_mode(plan, right_sole=(2, 1)),
        'lift_left_foot': lambda: append_mode(plan, left_sole=()),
        'move_left_foot_to_table': lambda: append_mode(plan, left_sole=(2, 1)),
        'lift_right_hand': lambda: append_mode(plan, right_ee=()),
        'move_left_hand_to_box': lambda: append_mode(plan, left_ee=(8, 1)),
        'lift_box': lambda: append_mode(plan, white_box=()),
        'move_box_to_table': lambda: append_mode(plan, white_box=(1, 2, 1)),
        'place_box_on_table': lambda: append_mode(plan, white_box=(1, 2, 1)),
        'final': lambda: append_mode(plan, left_sole=(2, 1), right_sole=(2, 1), left_ee=(9, 1), right_ee=(11, 1), white_box=())
    }

    # Execute the state machine
    current_state = 'initial'
    while current_state != 'final':
        next_state = transitions[current_state]
        actions[next_state]()
        current_state = next_state

    return plan
